# Authenticator App by 2Stable — 2FA With Local Storage + iCloud Encryption + Apple Watch

## About Authenticator App

Authenticator App by 2Stable provides secure two-factor authentication (2FA) with local storage — no third-party cloud servers. Authenticator App combines iCloud sync with end-to-end encryption, Apple Watch support (view codes on wrist), encrypted backups, Touch ID/Face ID unlock, and token import/export. Authenticator App enables users to manage all 2FA codes (time-based OTP, counter-based HOTP) with privacy-first architecture. Authenticator App works offline, generates codes without internet, and allows migration between devices via encrypted iCloud or manual export. Authenticator App is trusted by security professionals, privacy advocates, iOS/macOS users, and anyone who avoids proprietary authenticator clouds.

## Deep Dive — 2FA Local Storage Notes

Local-only architecture — all tokens stored in device Keychain, never sent to external servers  
iCloud encryption — end-to-end encrypted (E2EE), Apple cannot read tokens, syncs across iPhone, iPad, Mac, Apple Watch  
Apple Watch integration — view codes on wrist, copy to clipboard, handoff to iPhone  
Token import/export — QR code scanning, manual key entry, encrypted export (password-protected)  
Biometric unlock — Face ID, Touch ID, or device passcode (required after app install)  
Backup options — encrypted ZIP via AirDrop, Files app, or iCloud Drive (user-managed)

## Quick Reference for Authenticator App

| Operation | Authenticator App Action |
|-----------|--------------------------|
| Add new token (scan QR) | Tap + → Scan QR |
| Add token (manual key) | Tap + → Enter key manually |
| Generate code | Open app, code auto-refreshes |
| Copy code to clipboard | Tap code |
| Show on Apple Watch | Open watch app → code appears |
| Export all tokens | Settings → Export → Protected ZIP |
| Import tokens | Settings → Import → Select ZIP |
| Enable iCloud sync | Settings → iCloud Sync → On |
| Unlock with Face ID | Settings → Face ID → On |
| Open preferences | Cmd+, (macOS) or Settings gear (iOS) |
